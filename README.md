# دیده‌بان تصویر

خبرنامهٔ روزانهٔ فارسی پردازش تصویر، بینایی ماشین و هوش مصنوعی. هر شماره در یک فایل Markdown تاریخ‌دار نگهداری می‌شود و در زمان ساخت به صفحهٔ استاتیک تبدیل می‌شود. آخرین شماره در `/`، آرشیو در `/archive/` و نشانی دائمی هر شماره در `/issues/YYYY-MM-DD/` است. شماره‌های روزانه تاریخ خورشیدی دارند. آرشیو هفتگی پیشین با نشانی قدیمی نیز در دسترس است. فونت وزیرمتن همراه سایت است.

## راه‌اندازی در هم‌روش

1. در کنسول دارکوب، یک اپ از **منبع گیت** بسازید و دسترسی GitHub را برای همین مخزن بدهید.
2. مخزن `fayazamir1991/news` و شاخهٔ `main` را انتخاب کنید.
3. مسیر ساخت را ریشهٔ مخزن (`.`)، فایل ساخت را `Dockerfile` و پورت داخلی HTTP را `8080` تعیین کنید. مسیر بررسی سلامت `/healthz` است.
4. ساخت و استقرار خودکار با push روی `main` را فعال کنید و اولین استقرار را در پنل بررسی کنید. دامنهٔ اپ را در هم‌روش تنظیم کنید.

GitHub Actions روی push و Pull Request بیلد Docker می‌گیرد و پاسخ HTTP صفحهٔ اصلی، آرشیو، فونت و مسیر سلامت را می‌آزماید. ساخت و فعال‌کردن نسخهٔ عملیاتی را اتصال Git هم‌روش انجام می‌دهد. سایت برای نمایش محتوا به کلید API نیاز ندارد.

## اجرای محلی

```sh
docker compose up --build -d
```

سایت در `http://localhost:8080` در دسترس است. برای ساخت و پیش‌نمایش بدون داکر:

```sh
python3 build.py
python3 -m http.server 8080 --directory dist
```

## افزودن شماره و ادامه در Codex

منبع محتوا `content/briefings/` است. قرارداد فایل‌ها و معیارهای انتخاب در [راهنمای انتشار](PUBLISHING.md) نوشته شده‌اند. برای ادامهٔ توسعه در Codex، همین مخزن و شاخهٔ کاری را باز کنید. گزارش زمان‌بندی‌شده حوالی ۰۰:۰۵ بامداد تهران برای روز کامل گذشته تهیه می‌شود: ۱۰ پژوهش، دو بخش ۵ خبری و تا ۵ ریپوی گیت‌هاب با شواهد مربوط به همان روز. این ریپو محتوای منتشرشده، قالب و فرایند بیلد را نگه می‌دارد.


## نصب روی گوشی

سایت باید روی HTTPS باز شود. در Chrome اندروید گزینهٔ نصب برنامه یا «Add to Home screen» را انتخاب کنید. در Safari آیفون، از دکمهٔ Share گزینهٔ «Add to Home Screen» را بزنید. پس از نصب، سایت با نام و آیکون دیده‌بان تصویر در پنجرهٔ مستقل باز می‌شود.

صفحهٔ اصلی و آرشیو برای حالت آفلاین ذخیره می‌شوند. هر گزارشی که باز کنید نیز روی همان دستگاه ذخیره می‌شود. هنگام اتصال، آخرین نسخه از شبکه خوانده می‌شود. پس از انتشار نسخهٔ تازه، حافظهٔ کش برنامه نوسازی می‌شود. مسیرها یا گزارش‌هایی که هنوز باز نشده‌اند ممکن است آفلاین در دسترس نباشند.
